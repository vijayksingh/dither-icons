# Site copy

Write for designers and developers choosing an icon or adding it to a project. The drawings demonstrate the style; the text explains what is available and how to use it.

## Voice

- Use concrete nouns and verbs: icon, SVG, React component, preview, copy, download, replay.
- Describe a visible detail instead of praising the work. “The lid lifts, drops, and settles” tells the reader more than “a close you can feel.”
- Avoid claims about soul, character, humanity, delight, or how the visitor should feel. Do not describe our work as good, considered, careful, or meaningful.
- Use a heading to name the subject or action. Remove decorative labels that repeat it. Breadcrumbs and ordered installation steps remain useful navigation.
- Keep animation captions to one observable sequence. Preserve the icon's semantic identity and causal order (MOT-01, MOT-03). Captions do not claim an application action succeeded.
- State technical behavior precisely. Preserve reduced-motion behavior, SVG/React differences, accessible labeling requirements, licensing, and bundle limitations.
- Errors name the problem and a recovery action. Empty states explain the current filter; counts use the correct singular or plural.

## Terms

| Term | Use |
| --- | --- |
| Icon | One drawing in the catalog |
| Material | Dither, solid, or outline; the React prop remains `texture` |
| Animation | The icon's complete playback sequence |
| Frame | A paused position in an animation |
| Motion studio | The page for comparing and inspecting animations |
| View on npm | Opens the npm package listing |
| Install package | Opens installation instructions |
| Download React package | Downloads the versioned `.tgz` archive |
| Download SVG | Downloads the selected icon with the current export settings |

## Examples

| Avoid | Use |
| --- | --- |
| A little grain. A lot of character. | Dithered icons. In motion. |
| Small gestures. A little soul. | Compare animations |
| Everything your agent needs. | Download the docs |
| That page wandered off. | Page not found |
| A measured turn. A precise little click. | The gear turns and settles at the next position. |

The homepage, docs, AI guide, icon captions, README, metadata, and generated sharing images use the same vocabulary. Edit source content and regenerate the downloadable files; do not hand-edit generated copies. This is a copy refinement of the existing site, not a new visual system.
